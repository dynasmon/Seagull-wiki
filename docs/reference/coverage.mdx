## Remaining domains

All twelve schema families appear in [contracts](/docs/contracts/overview). All 28 backend ADRs appear under Architecture → Decisions. Every SQL migration is included in the [storage reference](/docs/reference/generated/storage). Runtime metric declarations appear in [metrics](/docs/reference/generated/metrics).

Installation, Docker/deployment, PKI, threat modeling, data ownership, configuration, troubleshooting, tests, CI, contribution, and status each have explicit sections. Native agent packaging, heartbeat, secure updates, SCA/FIM/process/network collectors, vulnerability matching, and V2 frontend architecture are documented as targets. No unsupported operational command is supplied to fill those gaps.

The documentation implementation itself is covered by [maintenance](/docs/development/documentation) and [static deployment](/docs/deployment/documentation).
