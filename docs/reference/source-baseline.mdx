## Evidence hierarchy

Current source and tests take precedence over historical notes. Compose and typed configuration establish wiring/defaults. Canonical contracts establish wire shape. ADRs explain decisions but retain historical statements. Roadmap cards establish target requirements, not implemented runtime behavior.

The V2 frontend has no application source. The separately inspected legacy frontend supplies visual context only.

## Local planning evidence

The parent workspace's `AGENTS-BACKLOG.md` and `AGENTS.md`, and backend `notes/` documents, are local architectural evidence. Some are intentionally not tracked upstream, so the guides cite them by path instead of linking to GitHub, and do not expose local credentials.
